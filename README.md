# «Զգույշ» (SafeArm) - Կիբեռխարդախության Բացահայտիչ

> **Հարթակներ՝** Web (Բրաուզեր) • Android (Capacitor / APK) • iOS (Xcode / PWA)

Այս պրոդուկտը նախագծված է հատուկ Հայաստանի շուկայի համար՝ բացահայտելու կեղծ **Հայփոստի (HayPost)**, **Իդրամի (Idram)**, բանկերի անունից ուղարկվող ֆիշինգային SMS-ները, ինչպես նաև Viber/WhatsApp-ով 5G կարգավորման անվան տակ կատարվող էկրանի կիսման (AnyDesk) խարդախությունները։

---

## 🚀 Ինչպե՞ս գործարկել (Web, Android, iOS)

### 1. Գործարկել Վեբ տարբերակը (Web / Browser)
```bash
# Գործարկել լոկալ սերվերը
npm run dev
```
Բացեք ձեր բրաուզերում `http://localhost:5173`։

---

### 2. Գործարկել Android տարբերակը (Native APK)
Նախագիծն արդեն պարունակում է պատրաստի Android Studio նախագիծը `android/` թղթապանակում։

```bash
# 1. Կառուցել վեբ կոդը և սինխրոնացնել Android-ի հետ
npm run build
npx cap sync

# 2. Բացել Android Studio-ում
npx cap open android
```
*Android Studio-ում կարող եք սեղմել **Run** (կամ `Build -> Build APK`) և անմիջապես տեղադրել հեռախոսի մեջ։*

---

### 3. Գործարկել iOS տարբերակը (iPhone / iPad)
iOS նախագիծը գտնվում է `ios/` թղթապանակում։

```bash
# 1. Սինխրոնացնել վերջին փոփոխությունները
npm run build
npx cap sync

# 2. Բացել Xcode-ում (macOS համակարգչով)
npx cap open ios
```
*Ինչպես նաև iPhone-ի վրա ցանկացած Safari բրաուզերից կարող եք սեղմել **«Add to Home Screen» (Ավելացնել գլխավոր էկրանին)**, և հավելվածը կտեղադրվի որպես լիարժեք PWA հավելված՝ առանց բրաուզերի հասցեագոտու։*

---

## 🌟 Հիմնական Ֆունկցիաները

1. **Կրկնակի մուտքագրում (Տեքստ կամ Սքրինշոթ).**
   - Տեղադրել պատճենված SMS/Viber տեքստը (Paste)։
   - Վերբեռնել էկրանի նկարը (Screenshot)։

2. **Ակնթարթային «Լուսացույց» վերլուծություն.**
   - 🔴 **Կարմիր (Խարդախություն է).** Հայտնաբերում է `haypost.cc`, `idram-support.site`, AnyDesk/5G թակարդներ, SMS կոդերի ու CVV-ի գողության փորձեր։
   - 🟡 **Դեղին (Կասկածելի է).** Կրճատ հղումներ (bit.ly, t.me), անհայտ ուղարկողներ։
   - 🟢 **Կանաչ (Անվտանգ է).** Պաշտոնական հավաստագրված դոմեններ (`haypost.am`, `idram.am`, `ameriabank.am` և այլն)։

3. **«Հարցնել հարազատին» մեկ կոճակով.**
   - Մեկ սեղմումով ուղարկում է նախապատրաստված զգուշացումը WhatsApp-ով, Viber-ով, Telegram-ով կամ հեռախոսի Share համակարգով։

4. **Պատրաստի 5 ռեալ օրինակներ ցուցադրության համար.**
   - Հայփոստի կեղծ SMS
   - Իդրամի արգելափակման սպառնալիք
   - 5G & AnyDesk զանգ
   - Կեղծ ներդրում (Գազպրոմ)
   - Օրինական Հայփոստի SMS

5. **Տարեցների ռեժիմ (55+).**
   - Մեծացված տառաչափեր, բարձր կոնտրաստ և ձայնային ընթերցման հնարավորություն։

6. **Նախագծի Հայեցակարգ (Բիզնես և Սոցիոլոգիա).**
   - Ներկառուցված ինտերակտիվ սլայդ՝ նախատեսված դասարանային շնորհանդեսների և ստարտափ քննարկումների համար։
